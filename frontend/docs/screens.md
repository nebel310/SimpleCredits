# Экраны и шаги USERFLOW

| Шаг USERFLOW | Экран | Адрес | Что на экране |
|---|---|---|---|
| 1–2. Регистрация и вход | Вход | `#/login` | Вкладки «Вход» и «Регистрация»; демо-аккаунты A–E и банк одной кнопкой |
| 3. Профиль компании | Профиль компании | `#/profile` | Реквизиты (подстановка из ЕГРЮЛ по ИНН, справка ФНС), финансы, кредитная история из БКИ (только для чтения); сохранение через `PATCH /auth/me`; после первого сохранения — «Подать заявку» |
| 4. Каталог | Продукты | `#/products` | 5 продуктов: суммы, сроки, ставки, особенности, цели, требования; «Подать заявку» |
| 5. Создание заявки | Новая заявка | `#/apply` | Одна форма: продукт или «Подобрать за меня» (видно, что подберёт банк), неподходящие компании продукты недоступны с причиной, сумма и срок в границах продукта, цель; сегмент определяет банк; платёж по диапазону ставок |
| 6. Обработка | Новая заявка → ожидание | `#/apply` | Этапы по событиям WebSocket: «Заявка отправлена → Данные получены → Оценка завершена → Решение готово» |
| 7. Результат | Карточка заявки | `#/applications/:id` | Над трекером — статус, пояснение и «Что дальше» с кнопками; условия предложения; «Что если?»; что повлияло на решение и советы; решение сотрудника банка; ответы ЕГРЮЛ/ФНС/БКИ; снимок данных компании; история событий |
| 7а. Ручная проверка | Заявка глазами банка | `#/bank/applications/:id` | Форма решения: одобрить, одобрить с другой суммой, отказать; комментарий для клиента |
| 7б. Принятие и выдача | Карточка заявки | `#/applications/:id` | «Принять предложение» → «Подтвердить и оформить» → номер модельного договора; «Отказаться» |
| 8. Просмотр позже | Мои заявки, Главная | `#/applications`, `#/home` | Список с исходом по типу результата и условиями предложения, новые сверху; живое обновление по WebSocket |
| Админ | Кабинет банка | `#/bank` | Всего заявок, средний балл, «Ждут проверки» (фильтр), разбивка по статусам, типу результата, продуктам и грейдам; все заявки; версия и метрики модели |
| Админ | Заявка глазами банка | `#/bank/applications/:id` | Та же карточка с баллом, PD, грейдом и всеми факторами, без кнопок клиента |

Состояния на всех экранах: загрузка (скелетон), пусто, ошибка с «Повторить», нет связи с сервером, сессия истекла.
