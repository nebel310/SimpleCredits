# Экраны и шаги USERFLOW

| Шаг USERFLOW | Экран | Адрес | Что на экране |
|---|---|---|---|
| 1–2. Регистрация и вход | Вход | `#/login` | Вкладки «Вход» и «Регистрация»; демо-аккаунты A–E и банк одной кнопкой |
| 3. Профиль компании | Профиль компании | `#/profile` | Реквизиты (подстановка из ЕГРЮЛ по ИНН, справка ФНС), финансы, кредитная история (подстановка из БКИ); сохранение через `PATCH /auth/me` |
| 4. Каталог | Продукты | `#/products` | 5 продуктов: суммы, сроки, ставки, особенности, цели, требования; «Подать заявку» |
| 5. Создание заявки | Новая заявка | `#/apply` | Одна форма: продукт или «Подобрать за меня», сумма и срок в границах продукта, цель, сегмент; сводка заявки и данных компании |
| 6. Обработка | Новая заявка → ожидание | `#/apply` | Этапы по событиям WebSocket: отправка → ЕГРЮЛ/ФНС/БКИ → скоринг → решение |
| 7. Результат | Карточка заявки | `#/applications/:id` | Статус и пояснение, балл, грейд, PD, решение и причины политики, условия, факторы модели, комментарий модели, ответы ЕГРЮЛ/ФНС/БКИ, снимок данных компании, история событий |
| 8. Просмотр позже | Мои заявки, Главная | `#/applications`, `#/home` | Список со статусами и баллами, новые сверху; живое обновление по WebSocket |
| Админ | Кабинет банка | `#/bank` | Всего заявок, средний балл, разбивка по статусам, продуктам и грейдам; все заявки; версия и метрики модели |
| Админ | Заявка глазами банка | `#/bank/applications/:id` | Та же карточка заявки, без кнопок клиента |

Состояния на всех экранах: загрузка (скелетон), пусто, ошибка с «Повторить», нет связи с сервером, сессия истекла.
