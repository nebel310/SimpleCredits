# SimpleCredits — фронтенд умного кредитного кабинета

Веб-кабинет предпринимателя и банка для Альфа-Хак 2026 («Альфа Будущее»), трек «Умный кредитный кабинет предпринимателя». Работает с бэкендом из `../backend` строго по `USERFLOW.md`: регистрация → профиль компании → заявка → проверка ЕГРЮЛ/ФНС/БКИ → решение скоринговой модели → результат в реальном времени.

**Все данные синтетические.** Доступа к ресурсам банка нет: госисточники — моки внутри бэкенда, скоринг — open-source модель из `../ml`.

## Запуск

### Всё вместе (Docker)

Из корня репозитория:

```bash
cp .env.example .env      # и раскомментировать значения
docker compose up -d --build
```

| Сервис | Адрес |
|---|---|
| Фронтенд | http://localhost:5500 |
| Бэкенд (Swagger) | http://localhost:3001/docs |

nginx внутри контейнера фронтенда отдаёт статику и проксирует `/api/*` и WebSocket на `backend:3001`, поэтому CORS не нужен.

### Разработка

Бэкенд и ML должны быть запущены (например, через `docker compose up -d db minio ml backend`).

```bash
cd frontend
npm ci
npm run dev               # http://localhost:5173, /api → http://localhost:3001
```

Если бэкенд на другом адресе — `BACKEND_URL=http://host:port npm run dev`.

### Переменные

| Переменная | По умолчанию | Зачем |
|---|---|---|
| `VITE_API_URL` | `/api` | Адрес API для браузера |
| `BACKEND_URL` | `http://localhost:3001` | Куда проксирует `npm run dev` / `npm run preview` |
| `VITE_ADMIN_EMAIL`, `VITE_ADMIN_PASSWORD` | `admin@admin.com` / `admin` | Кнопка «Войти как банк». Должны совпадать с `ADMIN_EMAIL` / `ADMIN_PASSWORD` бэкенда |

## Вход

- **Регистрация и вход** по email и паролю (`/auth/register`, `/auth/login`, JWT). Access-токен продлевается через `/auth/refresh`; если не вышло — сессия завершается.
- **Демо-аккаунты** — одна кнопка. При первом входе аккаунт регистрируется в бэкенде и получает синтетический профиль через `PATCH /auth/me`. Исход — то, что реально возвращает ML-модель для этих данных:

| Аккаунт | Сценарий | Статус | Решение модели |
|---|---|---|---|
| ИП «Компания A» | Стабильный бизнес, оборотный кредит 3 млн | `confirmed` | `approve` |
| ООО «Компания B» | Кредитная линия 20 млн при выручке 30 млн | `different` | `approve_with_conditions` → снизить до 15 млн; кнопка «Подать заявку на 15 000 000 ₽» |
| ООО «Компания C» | Высокая долговая нагрузка | `different` | `manual_review` (пограничная зона риска) |
| ИП «Компания D» | Продукт не выбран | `different` | `approve` без продукта — банк подобрал сам |
| ООО «Компания E» | Текущая просрочка 96 дней | `declined` | `decline` (`CURRENT_PAST_DUE`) |
| Банк · администратор | Роль `admin` | — | Все заявки, статистика, модель |

Статус `failed` появляется, когда ML недоступен: бэкенд отвечает 502/504, заявка сохраняется со статусом «Ошибка обработки».

| Экран | Адрес | Эндпоинты |

## Чего нет (по USERFLOW §11)

Мастера с черновиками, офферов с принятием, запроса документов, подписания, выдачи, графика платежей, ролей бухгалтера и наблюдателя, ручного андеррайтинга. Фронтенд показывает только то, что умеет бэкенд. Прошлая версия с этими экранами на моках осталась в истории ветки `frontend`.

## Структура

```
src/
  api/
    types.ts      типы из Pydantic-схем бэкенда
    http.ts       fetch, Bearer-токен, продление сессии, ошибки {detail}
    index.ts      все эндпоинты бэкенда
    session.ts    токены и пользователь (sessionStorage)
    ws.ts         WebSocket /ws/applications с переподключением
  lib/            вход, демо-аккаунты, подписи статусов, каталог, форматирование
  layout/         шапки кабинета клиента и банка
  pages/client/   главная, профиль, продукты, заявка, список заявок
  pages/bank/     все заявки и статистика
  pages/shared/   карточка заявки (общая для клиента и банка)
  ui/             компоненты на @alfalab/core-components, пиксельные иконки
  styles/         токены и стили
```

## Дизайн-система

- База — `@alfalab/core-components` (MIT): кнопки, поля, селекты, чекбоксы, радио и цветовые токены.
- Наш слой — лайм для пройденных шагов, пиксельные иконки (одна иконка — одно значение).
- Шрифты Unbounded и Onest (OFL) подключены локально — внешних запросов нет.
- Одна красная кнопка на экране — главное действие.
- Знак SimpleCredits — пиксельное сердце с искрой (`src/ui/Logo.tsx`), он же иконка вкладки (`public/favicon.svg`).

## Заметки для бэкенда

Бэкенд не менялся. Что заметили при интеграции (фронтенд это уже обходит):

- `GET /applications` и `GET /admin/applications` отдают заявки от старых к новым. Фронтенд собирает все страницы и показывает новые сверху.
- В корневом `.env.example` все строки закомментированы — после `cp .env.example .env` их нужно раскомментировать, иначе `docker compose` не поднимет базу.
